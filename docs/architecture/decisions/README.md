# Architecture decisions

Architecture decision records describe choices that are easy to accidentally
undo during maintenance.

- [ADR-001: Handwritten redirect responses](001-handwritten-redirect-responses.md)
- [ADR-002: Optional Redis-backed tracking](002-optional-redis-tracking.md)
- [ADR-003: Secret URL authorization for stats](003-secret-url-stats.md)

New ADRs should use the next number and contain status, context, decision,
consequences, and alternatives. A later ADR supersedes an earlier one rather
than silently rewriting history.
